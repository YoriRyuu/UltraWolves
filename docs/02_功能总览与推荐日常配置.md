# 教程 02：UltraWolves 全功能总览与推荐日常配置

本固件一共把全部改机功能分成三大类，帮助你一眼看懂 **“已经默认修好什么”、“推荐手动开什么”、“哪些先别开”**。

---

## 一、刷入即永久自动开启的底层保护（无需人工操作）

| 功能名 | 通俗解释 | 对手感/安全的意义 |
| --- | --- | --- |
| `atomic_accum` | 给传感器中断和主循环共用位移累加器加开关中断保护 | 杜绝高速 8K/20K 扫描时丢小幅移动计数的隐性竞态 |
| `queue_guard` | USB `EP81` 端点发包防重入/防覆盖保护 | 有线高回报率下微动事件与位移不相互覆盖丢包 |
| `debounce_instant` | 改完消抖后立刻刷新 `0x05 / 0xC1E8` 实时生效窗口 | 在软件里调 4 段 `0 ms` 消抖即时生效，无需拔线重启 |
| `fault_recovery` | 四类硬件异常中断自动写魔数弹射进 `0x3506` Bootloader | 就算极端异常也不会变砖，插着线就能直接救回 |
| `persistence v4` | 在 `0x000EA000` 单独开了一页带 CRC16 校验的配置区 | 所有 `adv` 高级参数掉电独立存储，与原厂 DPI/宏彻底隔离 |

## 二、真机实测通过、按需可随时开启的功能

> ⚡ **重要机制**：下面所有 `adv` 开关通过有线（`-Mode wired`）或无线（`-Mode wireless`）**无需重启立即生效**；默认只在内存运行（关掉鼠标电源即恢复），等你实际游戏试手感确认满意，再执行一次 `adv persist --action save --yes` 即可掉电永久保存。

| 命令开关 | 作用原理与实机实测状态 | 推荐度 |
| --- | --- | --- |
| **`adv fps`** | 切换 PAW3950 扫描帧率（内置 **38 档** + `255` 完全自定义）。比如选 `20k` 将 `07:42=20, 06:53=2, 06:62=2`，最高动态扫频可达约 20,000 FPS | ⭐⭐⭐⭐⭐ 强烈推荐（按续航与需求选档） |
| **`adv downshift`** | 写 `05:44 |= 0x40`（`0x05 -> 0x45`），防止传感器长时间低速/停顿时自动进入降频节能而出现首帧发粘 | ⭐⭐⭐⭐⭐ 推荐 FPS 开启 |
| **`adv fix-a`** | 用 `07:40=0x41` 开锁后把 `00:4E/4F/51/52` 内部 DPI 钳位上限由 `0x004F/0x0095` 抬高到 `0x0257`（`30,000 CPI`），解除高 DPI/切模式时的停顿降频上限 | ⭐⭐⭐⭐ 玩高压竞技可开启（真机已实测 `0x0257` 生效，注：超 7000 DPI 极少数表面静止时可能有 1 count 轻微抖动） |
| **`adv smoothing`** | 写 `0C:4D = 0x02`（原厂模式 1 默认 `0x90`），关闭高 DPI 下的内部平滑滤波，让原始轨迹更直接 | ⭐⭐⭐⭐⭐ 推荐高敏/原汁手感开启 |
| **`adv p3-ctrl --direct-motion 1`** | 让 `SPIM3` 传感器中断一拿到数据就尽量直接排队发出，减少主循环排队等待延迟。**无线实测 1 秒 `direct_tx_ok=477`、`0` 推迟、`0` 阻塞** | ⭐⭐⭐⭐⭐ 推荐开启（可先试玩观察 `p3-diag`） |
| **`adv ce-static`** | 将静态休眠/低 DPI 路径（Script B）的 `Bank 5 / Bank 9` 共 14 个调校寄存器改为更激进的高性能数值 | ⭐⭐⭐ 低 DPI（< 7000）FPS 玩家按需试用 |
| **`adv lod-raw`** | 绕过原厂三档粗调，直接写原始静默高度寄存器 `18:7A`（如 `0x00`=0.7mm、`0x85`=1.0mm、原厂 `0x8F`=2.0mm） | ⭐⭐⭐⭐ 需要极低 LOD 时强烈推荐 |
| **`adv anti-slam`** | 独立调节“落地瞬间”与“抬起瞬间”屏蔽微动防误触窗口（默认恢复原厂 `16 ms / 20 ms`，可各自设 `0..100 ms`） | ⭐⭐⭐⭐ 根据拍鼠习惯微调（如 `8 / 12` 或保持原厂 `16 / 20`） |
| **`adv p3-ctrl --plock 1`** | `TIMER1` 相位锁定，已修通 `IRQ9` 入口（`0x008842`）抓拍并扩大至 `±8 µs` 死区；真机实测 `learn -> entry` 误差 `0..1 µs`、`plock_adjusts=0` | ⭐⭐⭐⭐ 可按需开启并配合 `p1-cfg --mode learn` 使用 |

## 三、实验 / 禁用开关说明

- ℹ️ **`eager-wake`（`IRQ6` 静止秒醒）**：
  - 默认关闭；有需要可临时开启（需与 `direct-motion` 同开）并通过 `adv p2p3-state` 观察 `eager_wake_hits` 是否递增。
- 🚫 **`mouse-abs`（无线 `u16 ABS` 绝对位置包，默认关闭）**：
  - **搭配原厂接收器时严禁开启！** 开启后鼠标改发 `type 0x0A` 无线包，而未刷改版固件的原厂接收器不认识该包，会表现为**无线下光标不移动**（此时开关鼠标电源重启或有线执行 `adv mouse-abs --disable --yes` 即可立刻恢复）。

## 四、三套一键抄作业日常配置（无线模式下直接复制运行）

> 提示：如果刚从有线刷机切换回无线，建议先执行一次切回 8K：  
> `.\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 128 --yes`

### 方案 A：FPS 竞技极限响应档（续航会明显缩短，追求最低延迟与原汁微动/传感器）
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 128 --motionsync 0 --debounce 0 0 9 9 --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fps --preset 20k --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv downshift --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fix-a --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv smoothing --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --direct-motion 1 --yes
# 需要极低 0.7mm 抬起高度可附加下面这行：
# .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --enable --raw 0x00 --yes
# 确认一切正常后，掉电保存：
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action save --yes
```

### 方案 B：稳妥均衡日用档（极低功耗负担 + 保持核心修复与直发，适合平时打瓦/CS + 上班）
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 64 --motionsync 0 --debounce 0 0 9 9 --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fps --preset 10k --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv downshift --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fix-a --disable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv smoothing --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --direct-motion 1 --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action save --yes
```

### 方案 C：一键清空全部高级改机参数回到原厂传感器默认（不影响你的常规 DPI/按键）
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action reset --yes
```
