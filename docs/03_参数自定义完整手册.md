# 教程 03：参数自定义完整手册

本手册列出工具支持的所有 **常规配置** 与 **UltraWolves 高级调优参数**。  
所有命令默认都是 `--dry-run`（只检查不写入），**加上 `--yes` 才会真正在鼠标上执行**。  
在包根目录运行 `.\scripts\ultrawolves_cli.ps1 -Mode wired ...` 或 `-Mode wireless ...` 即可自动识别设备路径。

---

## A. 常规鼠标参数（导出 / 单项修改 / JSON 批量套用）

### 1. 导出、对比与套用 JSON
```powershell
# 导出当前配置到 backups\
.\scripts\01_备份当前配置.ps1 -Mode wireless

# 对比实时鼠标与目标 JSON 差异（0 写入）
.\scripts\ultrawolves_cli.ps1 -Mode wireless diff --input .\presets\example_config_8k_1600dpi.json

# 批量套用修改后的 JSON（例如改多档 DPI / 按键映射）
.\scripts\ultrawolves_cli.ps1 -Mode wireless apply --input .\presets\example_config_8k_1600dpi.json --yes
```
你可以复制 [presets/example_config_8k_1600dpi.json](../presets/example_config_8k_1600dpi.json) 来自行修改：
- `dpi_stage_count`：有效 DPI 档位数（`1..7`）
- `dpi_active_slot`：当前激活档位编号（`1..7`）
- `dpi_slots[i].x_cpi` / `y_cpi`：支持独立设置 X/Y 轴 DPI（单位为精确数值，例如 `1600`）
- `sleep_sec`：无线自动休眠时间（秒）

### 2. 单项快捷修改（`set`）
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless set `
  --polling-rate 128 `
  --dpi-slot 1 `
  --lod 2 `
  --motionsync 0 `
  --debounce 0 0 9 9 `
  --angle 0 `
  --sensor-mode 1 `
  --sleep-sec 30 `
  --yes
```

**回报率 `--polling-rate` 代码对照表**（注意有线与无线的代码区别！）：

| 目标回报率 | 无线模式 `-Mode wireless` 可用代码 | 有线模式 `-Mode wired` 可用代码 |
| --- | --- | --- |
| `1000 Hz` | `1` | `1`（或 `16`） |
| `500 Hz` | `2` | `2` |
| `250 Hz` | `4` | `4` |
| `125 Hz` | `8` | `8` |
| `2000 Hz` | `32` | ❌ 有线不支持 |
| `4000 Hz` | `64` | ❌ 有线不支持 |
| `8000 Hz` | **`128`** | ❌ 有线不支持（有线协议表仅到 1000Hz 代码位） |

- **`--lod` 档位**：有效值为 `1`（低）、`2`（中）、`3`（高）、`7`（更细自定义需改用下面的 `adv lod-raw`）。
- **`--debounce PRESS REL LOCK_P LOCK_R`**：四段按键消抖毫秒数（分别为按下消抖、松开消抖、锁存按下、锁存松开；全最低例如 `0 0 0 0` 或日常防双击 `0 0 9 9`）。修改后即时通过 `0xC1E8` 重载。

### 2. 自定义三元组（`--preset custom` / `255`）
只要满足 **`1 <= U <= 255`**、**`1 <= fast <= slow <= 255`**（慢速分频不得小于快速分频），可任意指定三元组：
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fps --preset custom --custom 20 5 2 --yes
```

## C. 传感器调优、直发与防误触高级命令

1. **停顿降帧控制（`downshift` + `fix-a`）**
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv downshift --enable --yes   # 或 --disable
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv fix-a --enable --yes       # 或 --disable
   ```
2. **关闭平滑滤波（`smoothing`）**
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv smoothing --enable --yes   # 写 0C:4D=0x02；--disable 回原厂
   ```
3. **静态高频调校复用（`ce-static`）**
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv ce-static --enable --yes   # 或 --disable
   ```
4. **原始抬起高度直写（`lod-raw`，Bank `0x18` Reg `0x7A`）**
   - 常用参考值：`0x00`（超低 ≈ `0.7 mm`）、`0x85`（约 `1.0 mm`）、`0x8F`（原厂 `LOD=2` 约 `2.0 mm`）。
   - 关闭后会立刻自动恢复原厂默认 `0x8F`（或随模式脚本同步）。
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --enable --raw 0x00 --yes
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --disable --yes
   ```
5. **落地 / 抬起防误触窗口自定义（`anti-slam`）**
   - 范围：均为 `0..100` 毫秒；原厂默认 `landing=16 ms`, `lifted=20 ms`。
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv anti-slam --landing-ms 12 --lifted-ms 16 --yes
   ```
6. **底层调度控制（`p3-ctrl`：`direct-motion` / `eager-wake` / `plock`）**
   - `direct-motion`：开启传感器直发（`1` 开 / `0` 关）
   - `atomic-accum` & `queue-guard`：强烈建议永远保持 `1`
   - `plock`：`TIMER1` 调相锁及其 `--period-us`（`50..2000` 微秒，默认 `125` 对应 8K）和 `--lead-us`（提前量，默认 `25` 微秒），需与 `--period-us` 和 `--lead-us` 同时指定才改定时参数。已修通 `IRQ9` 入口抓拍与 `±8 µs` 死区，建议先执行 `--mode learn` 学习一次偏移后自动切入 `entry` 稳态。
   - `eager-wake`：静止后 `IRQ6` 快速唤醒（`1` 开 / `0` 关，需同时开启 `direct-motion`），也可用单独子命令 `adv eager-wake --enable/--disable --yes`。
   ```powershell
   # 开启直接发送
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --direct-motion 1 --yes

   # 开启 plock（推荐先 learn 学习一次硬件固定偏移并自动进入 entry 闭环）
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --plock 1 --period-us 125 --lead-us 25 --yes
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv p1-cfg --mode learn --reset-minmax --yes
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv p1-state
   # 若需关闭 plock：
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --plock 0 --yes
   ```

## D. 实时状态查询与诊断寄存器命令

```powershell
# 总状态、能力掩码与 FPS/downshift/smoothing 三层状态
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv status

# 触发并回读 PAW3950 8 个白名单关键寄存器快照
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv snapshot --yes

# 查看 Phase 3 标志位 + 14 项性能计数器 + 清零计数器
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-state
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-diag
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-diag-reset --yes

# 查看 fix-a / plock 学习遥测 / W2 (ce-static, lod-raw, anti-slam, eager-wake)
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p1-state
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p2p3-state

# 读取 PAW3950 任意 Bank / 寄存器（只读探针）
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv reg-read --bank 0x00 --reg 0x4F --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv reg-read --bank 0x18 --reg 0x7A --yes
```

## E. 永久掉电保存与一键复位（`adv persist`）

所有 `adv` 改完后只在 RAM 热生效（方便放心试错——重启鼠标立即还原）：
```powershell
# 把当前生效的 FPS / downshift / fix-a / smoothing / direct-motion / ce-static / lod-raw / anti-slam 等写入 Flash 0x000EA000
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action save --yes

# 一键抹除独立配置页并立即恢复原厂传感器参数（不影响常规 DPI 和按键映射）
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action reset --yes
```
