# 00：UltraWolves 小白速通指南（人话版，3 分钟上手）

> 💡 **如果你不想研究寄存器和专业术语，只看这一篇就够了！**  
> 本指南用最直白的话带你：**5 分钟刷好固件 → 复制两条命令调好手感 → 随时一键撤销/退回原厂**。

---

## 一、UltraWolves 到底是干嘛的？（一句话讲清楚）

把它想象成给你的 **G-Wolves Fenrir Asym 8K** 鼠标“**免拆机换一套更跟手的引擎软件**”：
- **不用拧一颗螺丝**，一根 USB-C 线就能刷。
- **不动鼠标的“保命区”（Bootloader）**，而且有双重自动检查和自救机制，几乎不可能变砖。
- **所有改机参数默认只放内存里**——你先玩，觉得别扭把鼠标关掉重开就自动还原；觉得特别跟手，再敲一句“**存档**”才永久记住。
- 以后想退回官方出厂状态，**1 分钟随时还原**，也不丢你原来设好的 DPI 和按键。

---

## 二、动手前先确认这 3 件小事（必看！）

1. **型号必须完全对上**：只支持 **G-Wolves Fenrir Asym 8K**（PAW3950 `ID53`，原厂基础版本 `v1.00.39.00`）。别的型号鼠标千万别刷！
2. **电脑里装好 Python 3.12 或更高版本**：没装的话去 [python.org](https://www.python.org/downloads/) 下一个，安装界面最下方 **一定要勾选 `Add Python to PATH`**。
3. **刷固件那 1 分钟必须做到**：
   - 把电脑上插着的 **8K 无线接收器拔下来**（放在桌边，别插电脑上）；
   - **用有线 USB-C 线把鼠标直接连电脑**；
   - **关掉官网驱动软件和浏览器改键网页**（防止抢占鼠标）。

---

## 三、4 步傻瓜式刷机（一行一行复制粘贴运行）

先进入你解压出来的 `UltraWolves` 文件夹，在文件夹空白处 **点鼠标右键 → “在终端中打开”**（PowerShell 窗口），然后照顺序粘贴下面命令：

### 第 1 步：装工具环境（只在第一次使用时跑一遍）
```powershell
.\scripts\00_环境安装.ps1
```
- 等它自动装完依赖，最后出现绿色字 **`环境就绪！已内置 38 档 PAW3950 FPS 预设`** 就行了。

### 第 2 步：备份你现在的原厂配置（买个后悔保险）
```powershell
.\scripts\01_备份当前配置.ps1 -Mode wired
```
- 它会把你现在的 DPI、回报率、按键保存一份放进 `backups\` 文件夹里。

### 第 3 步：一键刷入 UltraWolves 增强固件
```powershell
.\scripts\02_有线刷入增强版固件.ps1
```
- 脚本会先自动检查你的鼠标对不对、有没有忘了拔接收器（检查过关绝对零风险才继续）；
- 然后会停下来问你是否确认：**输入大写的 `YES` 然后按回车**；
- 接下来大约等 **50 秒**（期间**千万不要拔线、不要关鼠标开关**），看到绿色字 **`刷写成功并已回到 0x3508 正常模式`** 就刷好了！

### 第 4 步：拔掉线，插回 8K 接收器恢复无线
- 拔掉鼠标上的有线，把 8K 无线接收器插回电脑，打开鼠标底部的开关即可无线使用。

## 四、这么多新功能都是啥意思？（人话翻译表）

刷完以后，鼠标里其实默认已经帮你修好了 5 个底层隐藏毛病（防高速丢计数、防有线丢包、消抖即时生效、卡死自动进恢复模式、独立配置页），下面这些是可以自己决定要不要开的开关：

| 开关名字 | 人话翻译（它是干啥的） | 建议怎么选？ |
| --- | --- | --- |
| **`fps`（比如 `20k` / `10k`）** | 控制传感器的“眼睛”每秒看多少次桌面。`20k` 最快最跟手但耗电多，`10k` 更省电。 | 🟢 **游戏选 `20k`，日常选 `10k`** |
| **`downshift`** | 防止鼠标停下来喘口气时，传感器偷偷“降频省电”，导致刚重新动的那一下发粘。 | 🟢 **建议打开** |
| **`fix-a`** | 配合上面一起解除传感器内部偷偷限制最大 DPI 的“暗锁”，彻底防停顿发粘（真机已完美修通）。 | 🟢 **打 FPS 建议打开** |
| **`smoothing`** | 关掉传感器内部自带的“美颜磨皮”（平滑滤波），让轨迹 100% 原汁原味指哪打哪。 | 🟢 **建议打开（=开启“关平滑”功能）** |
| **`direct-motion`** | 传感器一抓到移动就“走加急快递直接发出”，不跟着大部队在后面慢吞吞排队，降低延迟。 | 🟢 **无线实测超稳，建议打开** |
| **`lod-raw`** | 精细调节鼠标抬离桌面多高就停止感应。`0x00` 贴桌面极低（约 0.7mm），`0x85` 约 1.0mm，关掉恢复出厂 2.0mm。 | 🟢 **想要极低静默高度再开** |
| **`ce-static`** | 让 7000 DPI 以下的低灵敏度玩家，静止态也能用上高 DPI 那一套更激进的硬件调校。 | 🟡 **看个人手感，按需试用** |
| **`anti-slam`** | 拍鼠标落地 / 抬起时防止误触连击的保护时间（单位毫秒，出厂是落地 `16`、抬起 `20`）。 | 🟡 **一般不动或小幅微调** |
| **`persist save`** | **相当于游戏里的“保存存档”**。没运行这句之前，所有高级开关都是“临时试玩”，重开鼠标电源就清零还原。 | ⭐ **试玩满意后最后再敲一次** |
| **`plock`** | 已修通的定时器追相功能（`IRQ9` 入口 `0x008842` 抓拍 + `±8 µs` 死区），真机 `learn -> entry` 误差稳定在 `0..1 µs`、零误调。 | 🟢 **追求极致稳态时可按需开启** |
| **🚫 `mouse-abs`** | **千万别在原厂接收器上开！** 这是给以后配合改版接收器用的绝对坐标模式，在原厂接收器下打开会导致无线光标不动。 | 🔴 **保持关闭！** |

## 五、直接抄作业：两套最省心配置（无线模式下运行）

先确保鼠标用 **8K 接收器无线连着**、并且已经开机唤醒，在 `UltraWolves` 终端窗口直接整段复制粘贴：

### 套餐 1：FPS 竞技拉满档（跟手度拉到最满，续航会变短）
```powershell
# 1. 把无线切回真 8K 回报率 + 关 MotionSync + 0ms 低延迟消抖
.\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 128 --motionsync 0 --debounce 0 0 9 9 --yes

# 2. 开启 20k 扫频 + 双防发粘(downshift + fix-a) + 关平滑 + 快递直发
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fps --preset 20k --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv downshift --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fix-a --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv smoothing --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --direct-motion 1 --yes
```
👆 先这样去游戏里打两把试试手感！**觉得好用，再补下面这一句“保存存档”（这样以后关机重开也不会丢）：**
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action save --yes
```

### 套餐 2：均衡省电日用档（4K 无线 + 10k 扫频，兼顾跟手与续航）
```powershell
.\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 64 --motionsync 0 --debounce 0 0 9 9 --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv fps --preset 10k --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv downshift --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv smoothing --enable --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv p3-ctrl --direct-motion 1 --yes
.\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action save --yes
```

## 六、常用小调整（1 行命令搞定）

- **怎么单独调极低抬起高度（`0.7mm`）？觉得太低了怎么改回正常？**
  ```powershell
  # 极低 0.7mm（试完满意别忘了再运行一遍 persist --action save --yes）
  .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --enable --raw 0x00 --yes

  # 改成 1.0mm
  .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --enable --raw 0x85 --yes

  # 改回原厂默认抬起高度
  .\scripts\ultrawolves_cli.ps1 -Mode wireless adv lod-raw --disable --yes
  ```

- **怎么看一眼现在鼠标里到底开了啥？**
  ```powershell
  .\scripts\ultrawolves_cli.ps1 -Mode wireless adv status
  ```
  - 看到 `"requested_name": "20k"`、`"downshift": {"applied": true}`、`"smoothing": {"applied": true}` 就说明已经生效了！

- **刷完换回无线，感觉指针还是 1000Hz 不够丝滑？**
  - 运行一下这句切回 8000Hz（因为有线最高只支持到 1000Hz，恢复有线备份后会带着 `1000Hz` 设置）：
  ```powershell
  .\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 128 --yes
  ```

## 七、两颗“后悔药”（随时撤销）

1. **小后悔：不想用那些传感器高级开关了，一键还原出厂默认手感（保留改机固件本身和你的 DPI/按键）**
   ```powershell
   .\scripts\ultrawolves_cli.ps1 -Mode wireless adv persist --action reset --yes
   ```
2. **大后悔：不想玩增强固件了，彻底刷回 100% 纯净官方原厂**
   - 拔掉无线接收器、用有线连上鼠标，找来你官方升级包里的原厂固件文件（`Fenrir+035-8K_Mouse_App_FW_v1.00.39.00_20250605.hex`）：
   ```powershell
   .\scripts\03_恢复原厂固件.ps1 -StockHex "官方原厂HEX文件路径"
   ```
   - 大约 1 分钟后就干干净净变回刚拆封时的官方原厂固件了。
