# 教程 01：免拆机刷入 Phase 3+ 固件与安全回滚原厂

本工具采用 **严格白名单 + 拓扑门禁** 设计：未拔接收器、哈希不对、硬件不匹配时会自动报错中止，不会向鼠标发送任何写入指令。

---

## 一、准备工作（刷前必查）

1. **系统与软件**：Windows 10 / Windows 11，已安装 **Python 3.12 或更高版本**。
2. **仅保留有线 USB-C 直连**：
   - **务必拔掉电脑上的 8K 无线接收器（`0x33E4:0x3517`）** —— 刷写器检测到任何接收器都会硬拦截，防止跨设备错认。
   - 如鼠标与电脑有蓝牙配对，请先断开或关掉电脑蓝牙。
   - **关闭官方 G-Wolves 驱动软件及浏览器中的 WebHID 改键页面**，避免串口/HID 抢占。
3. **初始化命令行环境**（首次使用运行一次即可）：
   在解压目录右键“在终端中打开”，执行：
   ```powershell
   .\scripts\00_环境安装.ps1
   ```
   看到绿色提示 `环境就绪！已内置 38 档 PAW3950 FPS 预设` 即表示环境完成。

---

## 二、第 1 步：核对鼠标型号与备份原厂配置

1. **只读枚举核对设备**：
   ```powershell
   $env:PYTHONDONTWRITEBYTECODE="1"
   $env:PYTHONPATH="$PWD\tool"
   .\.venv\Scripts\python.exe -B -m fenrir.probe enumerate
   ```
   确认输出中**仅有一只**有线鼠标，包含：`0x33E4:0x3508 | class=mouse_app | if=2 up=0xFFFF usage=0x0000 exact_feat=True`。
   若想进一步确认版本与传感器芯片分支，可执行 L2 只读身份探针（把下面 `<PATH>` 换成上面输出的精确 `path=...`）：
   ```powershell
   .\.venv\Scripts\python.exe -B -m fenrir.probe l2 --target mouse-usb --path "<EXACT_HID_PATH>"
   ```
   确认看到：
   - `Mouse FW : v1.00.39.00 (tail=3508)`
   - `Sensor : ID53 (byte=0x50)`
   - `Verdict : MATCH`

2. **导出当前个人配置（重要！）**：
   ```powershell
   .\scripts\01_备份当前配置.ps1 -Mode wired
   ```
   会在 `backups\` 目录下生成 `backup_wired_时间.json`。如果之后需要恢复原厂或重设按键，直接用它还原即可。

---

## 三、第 2 步：有线刷入 UltraWolves 增强固件

### 推荐方式：运行一键安全脚本
```powershell
.\scripts\02_有线刷入增强版固件.ps1
```
脚本会自动依次执行：
1. 核对固件文件 SHA-256 是否严格等于 `F12621981F4AE57C8624606F60548827B2304D89AD647795224809F90346F8BD`；
2. 执行只读 `--dry-run` 预检（确认只有一只 `0x3508` 或 `0x3506` 有线鼠标、无接收器/BLE）；
3. 暂停提示你输入大写的 **`YES`** 二次确认；
4. 自动引导鼠标重启进入 Bootloader `0x3506`（`B0.02.03.00`）→ `Erase` → `Program` 写入全部 `3,968` 包（`0x00006000..0x00025000`，不足处按 `0xFF` 填充）→ **全部 `3,968` 包逐字节读回校验** → 发送 `Exit` 回到 `0x3508` 正常模式。
5. 全程约 **45～60 秒**，期间**不要拔线或动鼠标开关**，完成后自动恢复正常光标移动，并在 `backups\` 保存刷机报告 JSON。

### 等价手动原生态命令（高级玩家可选）
```powershell
$env:PYTHONPATH="$PWD\tool"
.\.venv\Scripts\python.exe -B -m fenrir.flasher flash-phase3plus `
  --hex ".\firmware\UltraWolves_Fenrir_Asym_8K_v1.00.39.00.hex" `
  --s4-canary-report ".\firmware\s4_bootloader_B0.02.03.00_verified.json" `
  --yes --confirm-phase3plus-s6 --report ".\backups\flash_report.json"
```

## 四、第 3 步：刷完立刻验真（只需 3 条只读命令）

```powershell
# 1. 查看增强版能力与当前状态
.\scripts\ultrawolves_cli.ps1 -Mode wired adv status

# 2. 抓取 PAW3950 8 寄存器实时快照（读真实传感器）
.\scripts\ultrawolves_cli.ps1 -Mode wired adv snapshot --yes

# 3. 查看核心保护与实时计数器
.\scripts\ultrawolves_cli.ps1 -Mode wired adv p3-state
```
验真合格特征：
- `adv status`：`magic: "FNR2"`、`caps_flags: 32767`（`0x7FFF`）、`fps_preset_count: 38`、`is_id53: true`、`last_err_name: "ERR_NONE"`；
- `adv p3-state`：`atomic_accum: true`、`queue_guard: true`；
- 你的原厂 DPI / 消抖 / 按键映射完整保留。

> 💡 **拔掉 USB 线、插回 8K 接收器切换无线后注意**：  
> 如果之前是在**有线状态**下恢复或导出过配置，`polling_rate_code` 可能是 `1`（`1000 Hz`）。切回无线后如果想恢复 **8K（`8000 Hz`）**，只需运行一条命令：  
> ```powershell
> .\scripts\ultrawolves_cli.ps1 -Mode wireless set --polling-rate 128 --yes
> ```

## 五、随时干净回滚官方原厂固件（60 秒复原）

如果你以后想把鼠标**彻底恢复到出厂纯净状态**（并把扩展区 `0x22A0C..0x24FFF` 全部擦回空白 `0xFF`），只需准备官方原厂升级包内的原版固件文件：
- 文件名：`Fenrir+035-8K_Mouse_App_FW_v1.00.39.00_20250605.hex`
- 官方原厂 SHA-256：`fd0ad5f1221bc0d227e423f87ec98d71033573e8a8a497856142c6000d12874f`

拔掉无线接收器、有线连上鼠标后执行：
```powershell
.\scripts\03_恢复原厂固件.ps1 -StockHex "你的官方原厂HEX路径\Fenrir+035-8K_Mouse_App_FW_v1.00.39.00_20250605.hex"
```
说明：该脚本会自动附带 `--wipe-ext` 参数，把原厂固件后方到 `0x25000` 的全部页按 4K 边界擦回 `0xFF`，同时**不发送**会清空个人配置的 `0xC0 0x02` 指令。

### 如果刷写中途意外断电导致鼠标停在 Bootloader（`PID=0x3506`）
- **不要慌也不要反复开关电源**：保持 USB-C 有线直连，直接重新运行 `.\scripts\02_有线刷入增强版固件.ps1` 或 `.\scripts\03_恢复原厂固件.ps1` 即可（工具会自动识别已处于 `0x3506` 的鼠标并继续重刷）。
- 实在需要时，也可以运行官方自带的 `FirmwareUpdate.exe`（仅插待恢复鼠标本体）兜底救回，刷完后再用 `backups\` 里的 JSON 恢复按键和 DPI。
